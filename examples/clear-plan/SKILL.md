# Clear Plan

When a request involves multiple steps:

1. Restate the intended outcome in one sentence.
2. List the necessary steps and the evidence that would verify success.
3. Identify missing information without inventing facts.
4. Make only the changes the user has authorized.
5. Report the result and any remaining work.

This example has no executable scripts, external services or authentication requirements.
