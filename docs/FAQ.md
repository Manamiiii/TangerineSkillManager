# 常见问题

[返回首页](../README.md) · [配置与恢复](CONFIGURATION.md)

### 本地库、来源、目标有什么区别？

来源是你导入或检查更新的地方；本地库是你维护的副本；目标是 Agent 实际读取 Skill 的目录。导入不会自动同步。

### 数据放在哪里，会上传吗？

Windows 新库位于 `%LOCALAPPDATA%/Tangerine/Data/TangerineSkillManager/Storage/vault/skills`，旧用户迁移后保留原库位置。macOS/Linux 仍使用系统用户数据目录的 `skill-manager/vault/skills`。配置、来源和安装记录只在本机保存，不上传。完整路径可在界面中查看，库目录可在设置中修改。[目录迁移及恢复说明](DATA_LAYOUT.md)

### copy 和 symlink 怎么选？

首次使用选默认的 copy。symlink 实时引用库内容；Windows 使用目录 junction。需要写入安装元数据的目标自动使用 copy。

### 遇到“冲突”要怎么做？

先查看目标路径和原内容，或换一个独立目标目录。应用不会提供一键强制覆盖外部文件。不要删除归属记录来绕过保护。[安全与恢复边界](../SECURITY.md)

### 公开 Git 仓库为什么不能访问？

请检查 URL、分支/标签与子目录。当前不支持私有仓库、认证、重定向和专用代理。解析到私网或保留地址时会阻止连接，某些 Fake-IP 代理也会触发这一限制。

遇到这种情况，可在 **设置 → 网络连接** 选择 **Cloudflare HTTPS DNS**，点击 **保存网络设置**，再重试。此选项默认关闭，仅在你发起联网操作时向 Cloudflare 查询目标域名；不发送 Skill 内容或本机路径给 DNS 服务，不改系统设置，也不自动切换解析方式。已通过应用内真实 Git、搜索和版本查询验证，但它不是代理，仍要求能够直接访问 HTTPS DNS 及目标网站。也可先把仓库下载到本机，再使用本地目录来源。[配置与隐私说明](CONFIGURATION.md#网络连接)

### 是否支持多个市场？

“来源 → 发现 Skill”提供 GitHub 主题仓库搜索和实验性的 SkillsMP 匿名搜索，各来源失败独立展示。GitHub 返回的是仓库，保存来源后还需发现并选择 Skill；不会一键安装未知内容。skills.sh、SkillsMP、ClawHub 也有浏览器入口，其中 skills.sh、ClawHub 尚无应用内搜索/制品下载适配。GitHub 与 SkillsMP 已通过保存的 HTTPS DNS 设置在应用内分别返回 20 条真实结果；接口和匿名限额可能变化。Registry 制品、npm/pip、自定义 CLI 和认证仍未实现。

### 如何更新？

应用自身：在“设置 → 应用版本更新”主动查询本仓库 GitHub Releases，查看纯文本发行说明，再打开发行页下载。便携版手动更新，不自动下载或安装，不需 token，也不需要 GitHub CLI。Skill 内容：检查来源更新 → 预览更新 → 应用此更新；预览 15 分钟有效，执行使用预览时固定的内容，配置或本地内容改变后必须重新预览。复制副本仍需预览同步，链接副本会实时反映库变化。

### 这些 Agent 都已验证会调用 Skill 吗？

模板按官方目录约定填写，并经本工具路径测试；没有逐一运行所有 Agent。它们可能同时读取兼容目录，也可能有版本、工具依赖或启用设置差异。Windows、WSL 和云端分别配置；同步成功不等于 Agent 已加载或调用 Skill。目录依据与限制见 [生态支持说明](ECOSYSTEM.md)。

### 会不会删除我的原始文件？

删除库 Skill 与卸载目标副本是两个操作。源目录保持不变；被外部修改的内容会阻止删除。崩溃恢复和同用户进程竞争的限制见 [安全说明](CONFIGURATION.md#安全说明)，不要把本工具当作备份软件。
