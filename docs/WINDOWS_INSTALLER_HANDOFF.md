# Windows 安装版交接

本轮范围只有 TangerineSkillManager，基于 main 的 `c45a350`；没有修改其他项目或业务数据格式。Windows x64 为当前目标，保留 macOS/Linux 构建结构，不宣称其实际安装已验证。

- 交付：0.1.0 当前用户 NSIS Setup 与 Portable，位于 `release/`。文件大小、SHA-256 和签名状态见 [发布清单](RELEASE_CHECKLIST.md) 与 [验证记录](VALIDATION.md)。本轮不上传安装包、不创建 Release。
- 身份：正式 app ID 为 `org.tangerineskillmanager.desktop`，安装 GUID 为 `048f50d3-d876-42d2-95f3-f0dce4cc270a`；数据位于操作系统用户数据目录的 `skill-manager`。本机目录与用户内容仅保存在本机配置中。
- 安装策略：无需管理员权限，开始菜单和 Windows 卸载入口，运行中拒绝安装/卸载，不强杀；升级与卸载默认保留配置、库、记录和同步副本。更新仍需手动下载安装。
- CI 修复：fixture 构建只传必要覆盖项，避免 electron-builder 重复合并资源数组造成并发复制失败。回归测试使用真实配置解析器。
- 远程结果：代码提交 `ad31e4c` 已推送 main，[Windows/macOS/Ubuntu CI](https://github.com/Manamiiii/TangerineSkillManager/actions/runs/41601852620) 全部通过；Windows fixture 构建、正式打包程序检查和 6 组安装生命周期回归成功。本次运行没有上传产物。后续结果记录提交仅改文档。
- 本机证据：68 项单元/集成测试；正式打包 EXE 与 Portable 各 21 项桌面检查；独立测试身份安装器 6 组生命周期检查；类型/格式/构建/隐私/包内容一致性检查通过。结果仅涵盖隔离 profile，不等于干净 Windows。
- 安全边界：测试安装前校验独立身份，保护已有安装和快捷方式；检查 HKCU、无 HKLM 登记、包内内容、x64 与 renderer 安全开关；不关闭用户正在使用的便携实例。诊断 profile 和报告不提交或上传。
- 未验证：正式身份交互向导、干净 Windows 普通账号、真实历史业务数据迁移、macOS 实机安装。0.0.9 fixture 使用当前代码，仅证明安装器升级流程。公网能力本轮未重测。
- 不适用：本项目没有 Dexie、阅读记录、OCR/地图或整库 JSON 导入导出；保留现有配置 JSON、来源导入和 Skill 迁移行为，没有为跨项目清单新增无关功能。

下一项发布门槛是在独立 Windows 普通账号环境按 [验收步骤](WINDOWS_ACCEPTANCE.md) 测试正式 Setup。测试机器或虚拟机均可，不要求在正在使用的个人环境覆盖安装。不需要重复已完成的自动检查。

## 最后技术复核（2026-11-03）

起始 main 与远端均为 `3c5004e`，工作区干净。正式 Setup 与 Portable 的大小、SHA-256、未签名状态均与上述记录一致；没有重新打包或替换候选。现有代码提交 `ad31e4c` 的三平台 CI 成功状态已重新查询确认。

只读安装前检查未发现正式 GUID 的 HKCU/HKLM 安装及卸载登记，也未发现同名开始菜单快捷方式；发现个人桌面已有快捷方式和运行中的便携实例，因此未启动正式 Setup、未运行正式卸载器、未修改任何现有入口。没有读取真实 Skill 库。仅更改 APPDATA/USERPROFILE 不能隔离 HKCU 的正式安装身份，不能用这种方式绕过保护完成正式安装验收。

当前 Portable 在新建临时 profile、虚构来源和独立用户级/项目级目标下再次通过 21 项桌面检查，包含同步、幂等预览和安全移除副本；正式应用目录的 8 个运行/许可文件、应用身份和示例通过一致性及隐私审计。技术复核只更新证据与依赖风险文档，没有改业务或数据格式。

正式身份仍缺少的证据：候选 Setup 交互向导与无提权安装、正式开始菜单/卸载入口、正式安装位置启动与重开恢复、运行中拒绝覆盖安装/卸载、退出后的覆盖安装、卸载保留及重装恢复。旧记录中另一个 hash 的生产安装器拒绝运行不能作为本候选完整生命周期的证据；测试身份的 6 组通过结果也不能替代这些检查。真实历史版本升级和干净机器验收继续单独标为未验证。

构建工具链的 15 项 moderate 告警已追踪到单一 minimatch 公告；生产依赖审计仍为 0，暂未发现受支持的低风险修复路径。影响、缓解条件及后续升级门槛见 [依赖复核](DEPENDENCY_REVIEW.md)。本机已有源码测试和安装 fixture 未为文档变更重复执行，新的 CI 结果以该文档提交的实际运行记录为准。

用户最少需要完成的是提供独立测试环境中的正式安装体验：安装并从开始菜单启动；用内置示例同步到测试目录并退出重开；验证运行中拒绝安装/卸载；退出后覆盖安装、卸载、重装并确认数据保留。可以由有该环境的维护者协助执行；日常电脑或新账号不自动等于没有开发依赖的干净 Windows。保持未签名、未公开下载状态，安装包等用户验收并确认上传后再发布。
